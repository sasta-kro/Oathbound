# Interface assets

`verdant_sanctum.svg` is an original vector illustration made for Oathbound.
Ambient motes and the creature gallery frames are drawn in Godot. Creature
portraits reuse the species' idle animations, with a shared crop across frames
to prevent the artwork from changing size as it animates.

## Fonts

- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

Both fonts are distributed under the SIL Open Font License. The corresponding
license files are included in `fonts/`. The FontVariation resources select a
500 weight using the integer OpenType `wght` tag (2003265652).
